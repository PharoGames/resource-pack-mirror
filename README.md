# PharoGames resource pack mirror

Machine-managed. Every file here is overwritten by `resource-pack-service` on each pack
rebuild, using a force-pushed parentless commit. Do not commit by hand: your commit will
be gone at the next publish.

This mirror exists because networks that front our servers (Minehut) only accept resource
pack URLs on their own host allowlist, which our normal presigned R2 delivery is not on.
The authoritative pack lives in R2; this is a delivery surface for those networks.
